05/05/2025 - 
	At the moment I'm still focused on boosting performance. I've explored a bit of feature selection, namely seeing whether removing game variables which can be explained by other game variables improves performance. For a few select variables, this does help. At the moment, I'm exploring the feasibility of the model specifications proposed by Bruno; he proposes a model which incorporates interaction terms in a "game variable : background variable" manner. At this point, the outputs of this model are all very low (<0.04), which results in all predictions being 0. I'm looking for ways to fix this. I think it might be the global shrinkage parameter in the prior.
